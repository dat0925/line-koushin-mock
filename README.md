# line-koushin-mock

サイトマイスター **LINE更新依頼 受付フロー** の動くモック（検討用）。

- 公開先: https://dat0925.github.io/line-koushin-mock/
- 閲覧には **PINコード** が必要（社内で共有）
- 画面の会社名・連絡先はすべて **架空のサンプル**。実際の送信は行わない

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | PIN入力画面 ＋ 暗号化したモック本体（単一ファイル） |

モック本体は AES-256-GCM で暗号化して埋め込んでいる（鍵導出 PBKDF2-SHA256 60万回）。
PINは保存しておらず、復号できたかどうかで判定している。

## 取り扱い

**public リポジトリである。** 4桁PINは「URLを知った人がうっかり開く」のを防ぐためのもので、機密保護にはならない。

## 更新のしかた

正本のモックと生成スクリプトは社内側（OneDrive）にある。

```
商品企画\サイトマイスター\LINE更新受付\更新依頼フロー_20261007\
  ├ 02_動くモック_20261007\index.html   ← 正本
  └ _build\build_publish.py             ← このリポジトリを生成する
```

```
python build_publish.py <PIN> <このリポジトリの作業フォルダ>
```

生成後、このリポジトリで commit / push する。
